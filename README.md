## コンテンツページ（contents.html）の中身

「Podcast」「学習コンテンツ」の**タブ切替**になっています（アンカーでのスクロールではなく、
クリックでその場のパネルが入れ替わる方式）。タブの切替は `tabs.js` が担当し、
中身の描画（stand.fm埋め込み・資料カード）は `contents.js` が担当します。

- **Podcastタブ（`#podcast`）** … stand.fmのPodcastバックナンバー（新しい順／古い順の並び替え、視聴済み管理）
- **学習コンテンツタブ（`#library`）** … Googleドライブに置いた学習資料の一覧（カテゴリ絞り込み）＋資料の使い方

他ページから `contents.html#podcast` や `contents.html#library` のようにリンクすると、
そのタブが最初から開いた状態で表示されます（`benefits.html` や `faq.html` からのリンクはこの仕組みを使っています）。

学習コンテンツの資料が0件のときは「Podcastを聴く」ボタンが出て、押すとPodcastタブに切り替わります。

### Podcastを追加する

`contents.js` 冒頭の `EPISODES` に1行足します。

```js
{ url: 'https://stand.fm/episodes/エピソードID', no: 10, theme: '', date: '8/1' },
```

- 表示順は `POD_ORDER`（`'newest'` / `'oldest'`）で切替
- 「視聴済み」はブラウザのlocalStorageに保存（サーバー送信なし）

### 学習資料を追加する

`contents.js` の `CONTENTS` に1件追記します。資料の実体は**Googleドライブ**に置き、
サイト側にはリンクと説明だけを持ちます。

```js
{
  title:    '生成AIリテラシー入門 振り返り資料',
  desc:     '権限管理とデータ保存先の考え方を、出典リンク付きで整理した資料です。',
  category: '現場での運用',                        // 下記カテゴリから選ぶ
  date:     '2026-08-10',                        // 公開日。新しい順に自動で並ぶ
  type:     'PDF',                               // スライド / PDF / 動画 / シート など
  url:      'https://drive.google.com/file/d/xxxx/view',
  source:   '2026/8/10 セミナー'                  // 任意。どの回の資料か
}
```

カテゴリ：`AI基礎` / `ツール活用` / `現場での運用` / `発信・キャリア` / `振り返り資料`
（増やす場合は `contents.js` 冒頭の `CATEGORIES` に追記）

**Googleドライブ側の設定（重要）**：共有設定を「リンクを知っている全員が閲覧可」にしてからURLを貼ってください。
「制限付き」のままだと参加者側で開けません。

資料が0件のときは「資料を準備しています」という案内とPodcastへの導線が自動で表示され、
1件でも追加すると自動でカード一覧に切り替わります。

## セミナーを追加・更新する（seminars.js）

`seminars.js` 冒頭の `SEMINARS` に1件追記します。

```js
{
  date: '2026-09-07',                    // 必須。YYYY-MM-DD
  dateLabel: '2026年9月7日（月）',
  time: '20:00〜21:00',
  title: 'セミナータイトル',
  subtitle: 'サブタイトル（なければ空文字）',
  speakerName: '講師名',
  speakerTitle: '所属・資格',
  price: '無料',
  thumb: 'assets/2026-09-07_theme-name.jpg',
  summary: 'カード・ポップアップに出る概要（1〜2文）',
  url: 'https://therapis10.com/seminars/xxxxx',
  tags: ['アーカイブ配信あり', '資料配布あり']
}
```

- 開催日を過ぎると自動で「開催終了」バッジになり、ボタンも「アーカイブを見る」に切り替わります
- サムネイルは `assets/YYYY-MM-DD_theme-name.jpg`。**16:9**で書き出し、200KB以下を目安に軽量化してください

## FAQを追加する（faq.html）

FAQも「参加について／内容について／セミナーについて／資料・コンテンツについて」の**タブ切替**です
（`tabs.js` を共用）。追加するときは、該当カテゴリの `.faq-list` 内に以下を追記するだけで、
タブの仕組みには手を加える必要はありません。

```html
<details class="faq-item">
  <summary>質問文</summary>
  <p>回答文。<a href="join.html">他ページへのリンク</a>も入れられます。</p>
</details>
```

カテゴリは 参加について / 内容について / セミナーについて / 資料・コンテンツについて の4つです。

## チャットボットについて（検討結果）

**導入は見送り。** GitHub Pagesは静的サイトのため、AIチャットボットを動かすにはAPIキーを
コード内に書く必要があり、公開ページから誰でも閲覧できてしまいます（キーの悪用・従量課金のリスク）。
回避するにはサーバーまたはクラウド関数の用意が別途必要です。

代替として「APIキー不要のFAQキーワード検索」も実装可能ですが、今回は見送りとしています。

## 公開方法（GitHub Pages）

1. 変更したファイルを「Add file → Upload files」でリポジトリ直下にアップロードしてCommit
   （`podcast.html` と `podcast.js` は削除済みのため、リポジトリ側でも削除してください）
2. 「Settings → Pages」→ Source「Deploy from a branch」、Branch `main` / `/(root)`
3. 「Enforce HTTPS」を有効化

## セキュリティの注意

- APIキー・アクセストークン・サービスアカウントJSON等の秘密情報は置かない
- 申込URLの招待コードは公開ページから誰でも見えます。限定運用したい場合は、後から無効化・差し替えできる招待リンクを使用してください
- Googleドライブの資料は「リンクを知っている全員が閲覧可」で公開されます。外部に見られて困る資料は載せないでください
- URL限定公開のstand.fmエピソードは「URLを知っていれば誰でも再生できる」状態です
